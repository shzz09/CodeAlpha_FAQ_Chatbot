# Askora – AI FAQ Chatbot

An AI-powered FAQ chatbot developed using Python and Natural Language Processing (NLP).

## Description

Askora is an intelligent chatbot that processes user questions and retrieves relevant answers from a predefined FAQ dataset using TF-IDF and cosine similarity.

## Features

- Interactive chatbot interface
- NLP-based text preprocessing
- TF-IDF vectorization
- Cosine similarity matching
- Match confidence score
- Fallback response for unmatched queries

## Technologies Used

- Python
- Streamlit
- NLTK
- Scikit-learn
- TF-IDF
- Cosine Similarity
- JSON
